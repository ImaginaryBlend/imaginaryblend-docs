# Reporting a bug

I’m doing my best to help everyone, fix all bugs, and work around the engine limitations, but some configurations may still cause problems. Reporting issues helps improve the product. A **precise bug report** shortens my response time and increases the chances of solving the problem.

Before reporting, check the [Troubleshooting](/help/troubleshooting) page – the problem may already have a known solution.

## What to include

1. Information about your configuration:
   - the Unreal Engine version you use,
   - specific settings enabled in the project (Lumen, Ray Tracing, Path Tracing, Forward Shading, Nanite, Substrate and everything that you think could cause the issue),
   - development platform (Windows, Linux, macOS),
   - target platform (VR device, mobile, macOS),
   - whether you can see the same issue in the demo maps.
2. Visual materials presenting the problem – a short video or screenshots.
3. A clear and detailed explanation, including the steps needed to recreate the problem on my machine.
4. The result you want to achieve after solving the issue.
5. A [minimal project](#minimal-project) presenting the issue.

Send the report by [email](mailto:imaginaryblend@gmail.com) or in your thread on Discord – see [Support](/help/support#contact).

## Minimal project

The easiest way to receive fast and direct support is to send me a minimal project demonstrating the problem. This reduces the time needed to reproduce the issue on my PC, which is often the most challenging part.

1. Download my product into a small (empty) project and reproduce the bug.
2. Prepare **repro steps**:
   - which level should be opened,
   - the list of steps to repeat to see the bug in your map,
   - details on testing the target platform.
3. Minimize the size of the project:
   - remove all content (textures, meshes) that is not crucial for the presentation of the bug,
   - remove the “Intermediate”, “Saved” and “Build” folders,
   - disable all external plugins and make sure the project does not depend on them.
4. Make sure that the bug can be reproduced with your description. **Test it!**
5. Pack it (zip), upload it to a file server and send me the link via the **support email** [imaginaryblend@gmail.com](mailto:imaginaryblend@gmail.com), together with your order ID.

::: danger
**Don’t share** minimal projects **publicly** on Discord or the Fab questions tab. Always use the support email for sending the files. I do not download files from unknown sources, so the order ID is required to verify your purchase.
:::
