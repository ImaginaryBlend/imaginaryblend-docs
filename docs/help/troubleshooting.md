# Troubleshooting

Most problems reported on support are already known and have a documented solution. Check this page before contacting me – it is usually the fastest way to fix the issue.

## Before you ask

1. Make sure you use the **newest version** of Fluid Flux – see the [Updating process](/getting-started/updating).
2. Check the [Limitations](/product/limitations) – there is a chance that your use case is not handled yet.
3. Make sure the problem is not listed in the [Known issues](/product/limitations#known-issues).
4. Check whether the same problem appears in the **demo maps**. If it does not, compare your setup with the demo.
5. Look for answers in [Questions & Answers](/product/faq) and the [Tutorials](/getting-started/tutorials).

## Common problems

| Problem | Where to look |
| --- | --- |
| Water does not move in the editor | [Real-time viewport](/getting-started/project-settings#real-time-viewport) |
| Shadows on the water look blocky | [Rendering settings](/getting-started/project-settings#rendering-settings) |
| Landscape or mesh is not rendered to the ground map | [Ground capture – Solving issues](/core-systems/ground-capture#solving-issues) |
| Simulation works in the editor but breaks in a build | [Ground capture – Solving issues](/core-systems/ground-capture#solving-issues) |
| Unexpected spikes destroy the simulation | [Simulation Domain – Solving issues](/core-systems/simulation-domain#solving-issues) |
| Coastline does not appear or looks different after play | [Coastline Domain – Solving issues](/core-systems/coastline-domain#solving-issues) |
| Boat flips or slides sideways | [Buoyancy – Troubleshooting](/core-systems/buoyancy#troubleshooting) |
| Interactions do not create ripples | [Interactions – Setting up interactions](/core-systems/interactions#setting-up-interactions) |
| Translucent objects disappear under the water | [Translucency](/core-systems/translucency) |
