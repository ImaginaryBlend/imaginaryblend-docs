# Introduction

- **Kategoria:** Blueprints
- **Wersja:** 3.0.4 (10.01.2025)
- **Wersje Unreal Engine:** 4.26 – 5.5+
- **Platformy:** VR, PC, Console

**Fluid Flux** to zaawansowany system wody oparty na 2D symulacji płytkiej wody (*shallow-water fluid simulations*). Zapewnia realistyczne interakcje powierzchniowe, falowanie oraz dynamikę obiektów.

## Wymagania wstępne
Do wygodnej pracy z systemem zalecana jest podstawowa znajomość:
1. Edytora Unreal Engine (UE Editor).
2. Skryptów wizualnych Blueprint.
3. Zarządzania zasobami w projekcie.
