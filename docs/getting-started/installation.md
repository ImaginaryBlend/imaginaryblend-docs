# Installation

Fluid Flux is distributed through the [Fab marketplace](https://www.fab.com/listings/196c70cd-1283-4249-bf6b-c3019d1cbe11) and is installed directly into your Unreal Engine project using the **Fab plugin** built into the editor. This chapter walks you through the first installation of the package.

::: info Already using Fluid Flux?
If the package is already installed in your project, follow the [Updating process](/getting-started/updating) instead.
:::

## Before you begin

- **Use the latest version.** Fluid Flux is updated frequently. The current version is listed on the Fab product page and at the top of the [Introduction](/introduction/).
- **Install from inside the editor.** The Epic Games Launcher library may not always show the newest release of a Fab product. Installing through the Fab plugin in the editor guarantees you receive the most recent build.
- **Back up your project.** Make a copy of the project or commit it to version control before adding the package.

## Installing from Fab

1. Enable the **Fab** plugin in your engine (**Edit → Plugins**).

   ![Fab plugin in the Unreal Engine plugin browser](https://d3kjluh73b9h9o.cloudfront.net/original/4X/9/f/8/9f898f60517183b78a290a08a82d52ce5c4157db.png)
2. Open your project, launch **Fab** from the **Content Browser** and make sure you are signed in to your Fab account.

   ![](/images/2024/11/fab.jpg)
3. Find **Fluid Flux** in the Fab window and open its page (double-click).

   ![](/images/2024/11/fffab.jpg)
4. Click **Add to Project**. The button is available once the product is in your Fab library. The installation works best with a clean **FluidFlux** folder – remove any previous copy of the package first.
